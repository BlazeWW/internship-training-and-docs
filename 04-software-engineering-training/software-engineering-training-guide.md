# Software Development and Software Engineering Training Guide

## Blaze Diagnostics App Technology Stack

The Blaze Diagnostics App uses:

- TypeScript
- Next.js
- Tailwind CSS
- PostgreSQL
- Drizzle ORM
- GitHub

## Training Areas

### 1. Git and GitHub

Learn:

- Repositories
- Branches
- Commits
- Pull requests
- Code reviews

### 2. TypeScript

Learn:

- Basic types
- Interfaces
- Functions
- Arrays and objects
- Type safety

### 3. React and Next.js

Learn:

- Components
- Props
- State
- Pages and routing
- Server and client components at a basic level
- Project structure

### 4. Tailwind CSS

Learn:

- Utility classes
- Layouts
- Spacing
- Responsive classes
- Cards, buttons, forms, and tables

### 5. PostgreSQL

Learn:

- Tables
- Rows and columns
- Primary keys
- Foreign keys
- Relationships
- Basic SELECT, INSERT, UPDATE, DELETE concepts

### 6. Drizzle ORM

Learn:

- What an ORM is
- Schema definitions
- Basic queries
- Migrations at a basic level

## First Practice Tasks

- Create a simple Next.js page.
- Create a reusable component.
- Style a card with Tailwind CSS.
- Create a mock customer table.
- Write a basic TypeScript interface for a vehicle or job card.
- Read the proposed Blaze Diagnostics user stories.
