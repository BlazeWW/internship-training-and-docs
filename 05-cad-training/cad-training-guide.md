# CAD Training Guide for Synergy Inc.

## CAD Internship Focus

CAD students will support the Synergy Inc. project through research, zoning, layout concepts, movement-flow thinking, exported drawings, and revision discipline.

## Training Areas

### 1. CAD Fundamentals

Revise:

- 2D drafting
- Layers
- Line weights
- Dimensions
- Annotations
- Blocks or reusable elements
- Drawing scale
- Exporting PDF and image versions

### 2. Space Planning

Research:

- Public access areas
- Restricted areas
- Staff areas
- Customer-facing spaces
- Vehicle flow
- Delivery flow
- Parking
- Safety zones

### 3. Mixed-Use Layout Thinking

Think about how the following spaces can operate near each other:

- Offices
- Restaurants
- Doctors' rooms
- Mechanical workshops
- Diamond cutting house
- Gold refinery
- Jewellers hub
- Auction house

### 4. Security-Sensitive Areas

Some spaces need stronger access control and separation from public zones:

- Diamond cutting house
- Gold refinery
- Jewellers hub
- Auction house storage or handling areas

### 5. GitHub for CAD Students

CAD students must also use GitHub for:

- Task tracking
- Research notes
- Exported review files
- Revision logs
- Final deliverables

## First Practice Tasks

- Read the Synergy Inc. project brief.
- Research one assigned space type.
- Create a zoning concept.
- Export a review version.
- Update the revision log.
- Commit changes with a clear message.
