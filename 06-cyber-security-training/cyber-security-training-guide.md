# Cyber Security Training Guide

## Cyber Security Internship Focus

Cyber security students will support both projects by helping the team think about safe access, data protection, secure workflows, and security risks.

## Training Areas

### 1. Web Application Security Basics

Learn:

- Authentication
- Authorization
- Role-based access control
- Input validation
- Error message safety
- Session risks

### 2. OWASP Top 10

Start with the OWASP Top 10 and identify how each category could apply to the Blaze Diagnostics App.

### 3. GitHub Security

Understand:

- Why secrets must not be committed
- What `.env` files are used for
- Why `.env.example` is safer than `.env`
- Why API keys and passwords must stay private

### 4. Customer Data Protection

The Blaze Diagnostics App may include:

- Customer names
- Contact details
- Vehicle information
- Quotes
- Invoices
- Job status information

Students should think about who should be allowed to access each type of data.

### 5. Security Reporting

Security findings should be written clearly:

- What is the risk?
- Where does it appear?
- Why does it matter?
- What is the recommended fix?
- How serious is it?

## First Practice Tasks

- Create a basic Blaze Diagnostics security checklist.
- Review customer-facing access risks.
- Review GitHub secret exposure risks.
- Identify role-based access requirements.
