# Blaze Diagnostics Project Brief

Blaze Diagnostics is a workshop management and client communication system for mechanical workshops.

## Purpose

The system should improve communication between workshops and customers by showing progress through the vehicle service or repair process.

## Key Features

- Customer management
- Vehicle management
- Job cards
- Quote approvals
- Parts ordered and delivery updates
- Mechanic progress updates
- Customer notifications
- Invoicing
- Dashboard visibility
- Activity logging
- Role-based access control

## Current Technology Stack

- TypeScript
- Next.js
- Tailwind CSS
- PostgreSQL
- Prisma currently present in the uploaded app
- Drizzle ORM only if migration is approved later
- GitHub for version control
