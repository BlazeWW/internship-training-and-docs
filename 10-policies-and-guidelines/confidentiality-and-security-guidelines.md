# Confidentiality and Security Guidelines

Students must handle project information responsibly.

## Rules

- Do not share project files outside the approved channels.
- Do not share login details or passwords.
- Do not commit passwords, API keys, or secrets to GitHub.
- Do not work on production systems unless explicitly instructed.
- Do not delete or overwrite another student's work.
- Ask before installing third-party packages or tools for project work.
- Report mistakes early.

## Software Security Notes

- `.env` files must not be committed.
- Use `.env.example` to show required variable names without real values.
- Error messages should not expose sensitive technical details.
- Customer data must only be visible to authorised users.

## CAD Security Notes

- Sensitive facility layout details should be handled carefully.
- Restricted areas should be labelled appropriately.
- Do not publish sensitive layout exports publicly without approval.
