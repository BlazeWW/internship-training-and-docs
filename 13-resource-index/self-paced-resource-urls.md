# Self-Paced Resource URLs for Interns

This document gives each group a practical set of free learning resources to work through at their own pace. The resources are intentionally video-heavy, with freeCodeCamp used wherever possible because the courses are free, structured, and comprehensive.

Students are not expected to complete every resource immediately. The goal is to build enough basic knowledge to contribute to project tasks, ask better questions, and understand the work being assigned.

## How to Use This Resource List

1. Start with the common resources.
2. Move to your group-specific section.
3. Watch with a notebook open.
4. Pause and practise the commands or concepts.
5. Write down questions for the next informal check-in.
6. Add your progress to your daily or weekly update.

Suggested progress note format:

```markdown
## Resource Progress

Resource watched/read:
Time spent:
What I understood:
What I still do not understand:
How this applies to my internship tasks:
Questions for Ben / mentor:
```

# 1. Common Resources for All Students

All groups should understand GitHub, Markdown, remote communication, and how to document progress.

## Required

| Topic | Resource | URL | Why it matters |
|---|---|---|---|
| freeCodeCamp YouTube Channel | freeCodeCamp.org YouTube | https://www.youtube.com/@freecodecamp | Main video-learning source for the internship. |
| freeCodeCamp Courses | freeCodeCamp.org Courses | https://www.youtube.com/@freecodecamp/courses | Structured learning paths for development, backend, DevOps, and security. |
| Git and GitHub | Git and GitHub for Beginners - Crash Course | https://www.youtube.com/watch?v=RGOj5yH7evk | Required for all students because all repositories use GitHub. |
| GitHub Basics | GitHub Hello World | https://docs.github.com/en/get-started/start-your-journey/hello-world | Official GitHub guide to repositories, branches, commits, and pull requests. |
| Markdown | Markdown Basic Syntax | https://www.markdownguide.org/basic-syntax/ | Required for README files, notes, issues, progress updates, and documentation. |
| VS Code | Visual Studio Code Intro Videos | https://code.visualstudio.com/docs/getstarted/introvideos | Useful for software, cloud, and security students working with repositories. |

## Expected outcome

Each student should be able to:

- Navigate a GitHub repository.
- Understand what a branch is.
- Understand what a commit is.
- Understand what a pull request is.
- Open and edit Markdown files.
- Submit clear progress updates.
- Ask questions using screenshots, error messages, and context.

# 10. How Students Should Report Learning Progress

Each student should include resource progress in their weekly update.

```markdown
# Weekly Learning Progress

## Name

## Group

## Resources completed this week

## Concepts I understand better now

## Concepts I still need help with

## How this connects to my assigned project tasks

## Questions for next informal check-in
```

The goal is not to watch videos passively. The goal is to connect the learning to the actual tasks in GitHub.
