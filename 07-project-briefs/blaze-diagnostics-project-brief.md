# Blaze Diagnostics App Project Brief

## Project Overview

The Blaze Diagnostics App is a software system being developed for mechanical workshops.

The goal is to improve communication between workshops and clients by giving customers better visibility into what is happening with their vehicles.

## Key Features

The system should support:

- Vehicle job tracking
- Quote approvals
- Parts ordered
- Parts delivery updates
- Mechanic progress updates
- Client communication
- Notifications when a vehicle is ready
- Invoicing
- Workshop workflow management

## Technology Stack

- TypeScript
- Next.js
- Tailwind CSS
- PostgreSQL
- Drizzle ORM
- GitHub

## Main User Roles

- Workshop Admin
- Service Advisor
- Mechanic
- Customer
- System Admin, if required

## Initial Project Areas

- Authentication and user access
- Customer management
